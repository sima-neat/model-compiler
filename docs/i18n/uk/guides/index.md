# Скомпілюйте модель.

**Model Compiler** — це набір інструментів SiMa.ai, який перетворює навчену модель на артефакт, який середовище виконання Neat може виконувати на MLSoC. У шляху vision/ONNX використовується пакет `afe` Python для перевірки сумісності, підготовки графа, квантування, компіляції та перевірки точності та продуктивності.

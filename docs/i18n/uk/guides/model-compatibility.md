# Сумісність моделей.

Набір інструментів для компіляції SiMa.ai імпортує **ONNX** моделі та готує оператори для апаратного прискорювача машинного навчання (MLA). Використовуйте цю сторінку, щоб перевірити підтримку операторів, перш ніж підготувати модель для Modalix.

## Обмеження

- **Додавання** — обидва операнди мають однакову форму, або рівно один з операндів є скаляром, або обидва операнди можна звести до сумісної форми.
- **ArgMax** — параметр keepdim=True, застосовується зменшення розмірності по осі каналів.
- **AveragePool** — розширення = 1, режим округлення до більшого значення = False, розмір < 128, враховувати доповнення = True. Якщо застосовується глобальне об’єднання, обмеження за розміром відсутнє.
- **BatchNorm** — режим навчання = 0 (SW)
- **Об’єднання** — не виконується по осі пакету.
- **Conv** — значення кроку має бути в діапазоні [1, 31]. Значення розширення має бути в діапазоні [1, 63].
- **ConvTranspose** — усі коефіцієнти розширення дорівнюють 1. Використовується глибинна згортка або кількість груп дорівнює 1. Крок змінюється в діапазоні: [1, 2, 4, 8, 16]. Якщо використовується глибинна згортка, крок має бути 1 або 2.
- **CumSum** — параметр «reverse» має значення 0 (SW). Розмір на осі підсумовування не повинен перевищувати 257 (SW). Має бути точно одна вісь підсумовування (SW). Вісь має бути константою (HW).
- **Div** — Обидва операнди мають однакову форму, або рівно один з операндів є скаляром, або обидва операнди можна звести до сумісної форми.
- **Einsum** — рівняння Einsum є обчисленням матричного добутку для пакету даних.
- **Зібрати** — індекси мають бути константою і повинні бути 0D або 1D. (Апаратне забезпечення)
- **Gelu** — приблизно = «жоден» (SW)
- **GridSample** — режим встановлено на «лінійний», а параметр padding_mode не має значення «віддзеркалення».
- **InstanceNorm** — призначено лише для тензорів розмірності 4D і 5D. (SW)
- **LayerNorm** — застосовується лише до канальної осі.
- **MaxPool** — розширення (dilation) = 1, режим округлення до більшого значення (ceil_mode) = False, розмір < 128. Якщо застосовується глобальне об’єднання, обмеження за розміром відсутнє.
- **Mul** — Має таку саму форму, або рівно один із вхідних аргументів є скаляром, або обидва вхідні аргументи можна звести до сумісної форми.
- **Додавання нулів (Padding)** — шляхом перетворення на середній пул. Додавання нулів у пакетній або канальній розмірності не підтримується. Підтримується лише режим «константа» зі значенням 0.
- **Pow** — вхідний показник степеня є скалярною константою, що дорівнює 0,5, -0,5, 2 або 3. (SW)
- **PRelu** — постійне значення альфа на осі каналу.
- **ReduceMean** — параметр keepdims має значення True, а зменшення відбувається лише за просторовою віссю, і розмір цієї осі менший за 128.
- **ReduceMin** — поки що не підтримується. (SW)
- **ReduceSum** — для операції зведення в одному вимірі вісь визначає лише просторовий вимір. (SW) Якщо всі осі є просторовими, обмежень щодо розміру немає; в іншому випадку розмір у просторових осях має бути меншим за 128. (SW)
- **Зміна форми** — параметр allowzero = 0 (SW). Форма не може бути порожньою. (SW)
- **Зміна розміру** — режим coordinate_transformation_mode зі значенням 'tf_crop_and_resize' не підтримується. Якщо метод задано як 'linear' або 'bilinear', то значення coordinate_transformation_mode має бути 'half_pixel'…
- **RMSNorm** — тип зберігання stash_type = 10 (FLOAT16) не підтримується. (SW)
- **Slice** — Позитивні зрушення. (SW)
- **Softmax** — обчислення виконуються над віссю каналів.
- **Sub** — однакова форма, або рівно один із вхідних аргументів є скаляром, або обидва вхідні аргументи можна звести до сумісної форми.
- **Покажчик** — значення індексу має бути константою, і воно має дорівнювати 0D або 1D. (SW)
- **Транспонування** — не передбачає використання пакетної осі.
- **Дисперсія** — обчислюється для всіх просторових вимірів.

# 編譯模型

**Model Compiler** 是 SiMa.ai 工具鏈，它將訓練好的模型轉換為可在 MLSoC 上由 Neat 執行時環境執行的成品。vision/ONNX 路徑使用 `afe` Python 套件來檢查相容性、準備圖，進行量化、編譯，並驗證準確性和效能。

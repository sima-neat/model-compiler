# モデルをコンパイルする。

**Model Compiler** は、学習済みのモデルを、Neat ランタイムが MLSoC 上で実行できる成果物へと変換する、SiMa.ai ツールチェーンです。vision/ONNX パスでは、`afe` Python パッケージを使用して、互換性を確認し、モデルを準備し、量子化し、コンパイルし、精度とパフォーマンスを検証します。

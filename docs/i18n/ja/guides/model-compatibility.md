# モデルの互換性

## 制約

- **加算** — 形状が同じ、または入力のいずれか 1 つがスカラーである、または両方の入力がブロードキャスト可能である。
- **ArgMax** — keepdim=True を指定し、チャンネル軸に沿って次元を縮小します。
- **AveragePool** — 拡張率（Dilation）=1、天井関数モード（ceil_mode）=False、サイズ<128、パディングを含める（count_include_pad）=True。グローバルプーリングの場合は、サイズの制限はありません。
- **BatchNorm** — トレーニングモード = 0（SW）
- **Concat** — バッチ軸には適用されません
- **Conv** — ストライドの値は[1, 31]の範囲で、ダイレーションの値は[1, 63]の範囲で設定してください。
- **ConvTranspose** — すべての膨張率は1に設定されます。深さ方向の畳み込みまたはグループ数は1です。ストライドの範囲は[1, 2, 4, 8, 16]です。深さ方向の畳み込みを行う場合、ストライドは1または2でなければなりません。
- **CumSum** — reverse パラメータは 0 に設定します（SW）。合計演算を行う軸のサイズは 257 以下である必要があります（SW）。合計演算を行う軸は 1 つだけである必要があります（SW）。軸は定数である必要があります（HW）。
- **Div（除算）** — 形状が同じであるか、または入力のいずれか1つがスカラーであるか、または両方の入力がブロードキャスト可能である。
- **アインシュタインの総和記法** — アインシュタインの総和記法は、バッチ行列乗算の一種です。
- **Gather** — インデックスは定数でなければならず、0次元または1次元でなければなりません。（ハードウェア）
- **Gelu** — 近似値 = 「なし」（SW）
- **GridSample** — モードは「線形」であり、パディングモードは「リフレクション」ではありません。
- **InstanceNorm** — 4次元および5次元のテンソルにのみ適用されます。（SW）
- **LayerNorm** — チャネル軸のみに適用
- **MaxPool** — 拡張率（Dilation）=1、天井関数モード（ceil_mode）=False、サイズ<128。グローバルプーリングの場合は、サイズの制限はありません。
- **Mul（乗算）** — 形状が同じであるか、または入力のいずれか1つがスカラーであるか、または両方の入力がブロードキャスト可能である。
- **パディング** — 平均プーリングへの変換を通じて行われます。バッチ次元またはチャネル次元でのパディングはサポートされていません。値が0の「定数」モードのみがサポートされます。
- **Pow** — 入力される指数は、スカラー定数 0.5、-0.5、2、または 3 です。（SW）
- **PRelu** — チャネル軸に沿った一定のアルファ値
- **ReduceMean** — keepdims=True を指定し、次元削減の対象は空間次元のみとし、そのサイズを 128 未満にする。
- **ReduceMin** — 現時点ではサポートされていません。（SW）
- **ReduceSum** — 1次元の次元削減の場合、軸は空間次元のみです。（SW）すべての空間軸に対しては、サイズの制限はありません。それ以外の場合は、空間軸におけるサイズは128未満です。（SW）
- **形状の変更** — allowzero = 0（SW）。形状は空にできません。（SW）
- **サイズ変更** — coordinate_transformation_mode='tf_crop_and_resize' はサポートされていません。メソッドが「線形」または「双線形」の場合、coordinate_transformation_mode は「ハーフピクセル」である必要があります。
- **RMSNorm** — stash_type = 10（FLOAT16）はサポートされていません。（SW）
- **Slice** — 良い進展が見られる。（SW）
- **ソフトマックス** — チャネル軸に沿って処理
- **Sub（減算）** — 形状が同じであるか、または入力のいずれか1つがスカラーであるか、または両方の入力がブロードキャスト可能である。
- **Take** — インデックスは定数でなければならず、0Dまたは1Dでなければなりません。（SW）
- **転置** — バッチ軸を含まない
- **分散** — すべての空間次元にわたって計算します。

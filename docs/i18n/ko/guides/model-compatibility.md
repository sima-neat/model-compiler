# 모델 호환성

SiMa.ai 컴파일 도구 체인은 **ONNX** 모델을 가져와 머신 러닝 가속기(MLA)용 연산자를 준비합니다. 이 페이지를 사용하여 Modalix용 모델을 준비하기 전에 연산자 지원 여부를 확인하세요.

## 지원되는 연산자

## 제약 조건

- **더하기** — 모양이 같거나, 입력 중 정확히 하나가 스칼라이거나, 두 입력 모두 브로드캐스팅 가능합니다.
- **ArgMax** — keepdim=True로 설정하고 채널 축을 기준으로 차원을 축소합니다.
- **AveragePool** — 팽창률=1, 올림 모드=False, 크기<128, 패딩 포함 여부=True. 전역 풀링인 경우 크기 제한 없음.
- **배치 정규화(BatchNorm)** — 훈련 모드 = 0 (소프트웨어 방식)
- **Concat** — 배치 축에 적용되지 않음
- **Conv** — 스트라이드 값은 [1, 31] 범위 내에 있어야 합니다. 다일레이션 값은 [1, 63] 범위 내에 있어야 합니다.
- **ConvTranspose** — 팽창률은 모두 1과 같습니다. 깊이별 컨볼루션 또는 그룹 수는 1입니다. 스트라이드는 다음 범위 내에 있어야 합니다: [1, 2, 4, 8, 16]. 깊이별 컨볼루션인 경우, 스트라이드는 1 또는 2여야 합니다.
- **CumSum** — reverse = 0(소프트웨어). 합계가 계산되는 축의 크기는 257 이하이어야 합니다(소프트웨어). 정확히 하나의 합계 축이 있어야 합니다(소프트웨어). 축은 상수가 되어야 합니다(하드웨어).
- **Div** — 두 입력의 형태가 동일하거나, 정확히 하나의 입력이 스칼라 값이고, 또는 두 입력 모두 브로드캐스팅 가능해야 합니다.
- **아인슈타인 합(Einsum)** — 아인슈타인 합 방정식은 배치 행렬 곱셈입니다.
- **수집** — 인덱스는 상수여야 하며, 0차원 또는 1차원이어야 합니다. (하드웨어)
- **겔루(Gelu)** — 근사값 = "없음"(SW)
- **GridSample** — 모드는 '선형'이고 패딩 모드는 '반사'가 아닙니다.
- **인스턴스 정규화(InstanceNorm)** — 4차원 및 5차원 텐서에만 적용됩니다. (SW)
- **레이어 정규화(LayerNorm)** — 채널 축에 대해서만 적용
- **MaxPool** — 팽창률=1, 올림 모드=False, 크기<128. 전역 풀링인 경우 크기 제한 없음.
- **Mul** — 모양이 동일하거나, 입력 중 정확히 하나가 스칼라 값이거나, 두 입력 모두 브로드캐스팅 가능합니다.
- **패딩** — 평균 풀링으로 변환하여 적용합니다. 배치 또는 채널 차원에서 패딩을 적용하는 것은 지원하지 않습니다. 값 0으로 설정된 '상수' 모드만 지원합니다.
- **Pow** — 입력 지수는 스칼라 상수 0.5, -0.5, 2 또는 3입니다. (SW)
- **PRelu** — 채널 축에 대해 일정한 알파 값 적용
- **ReduceMean** — keepdims=True로 설정하고, 축소할 축은 공간 차원에 한정하며, 크기는 128보다 작아야 합니다.
- **ReduceMin** — 아직 지원되지 않습니다. (SW)
- **ReduceSum** — 1차원 축소 연산의 경우, 축은 공간 차원에만 적용됩니다. (SW) 모든 공간 축에 적용할 경우, 크기 제한은 없습니다. 그렇지 않은 경우, 공간 축의 크기는 128보다 작아야 합니다. (SW)
- **모양 변경** — allowzero = 0(SW) 모양은 비어 있을 수 없습니다. (SW)
- **크기 조정** — coordinate_transformation_mode='tf_crop_and_resize'는 지원되지 않습니다. 메서드가 'linear' 또는 'bilinear'인 경우 coordinate_transformation_mode는 'half_pixel'이어야 합니다.
- **RMSNorm** — stash_type = 10(FLOAT16)은 지원되지 않습니다. (소프트웨어 관련)
- **슬라이스** — 긍정적인 발전. (SW)
- **소프트맥스** — 채널 축을 기준으로 적용
- **Sub** — 모양이 동일하거나, 입력 중 정확히 하나가 스칼라 값이거나, 두 입력 모두 브로드캐스팅 가능합니다.
- **Take** — 인덱스는 상수여야 하며, 0D 또는 1D여야 합니다. (SW)
- **전치** — 배치 축을 포함하지 않음
- **분산** — 모든 공간 차원에 대해 계산

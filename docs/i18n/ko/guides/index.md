# 모델을 컴파일합니다.

**Model Compiler**는 SiMa.ai 학습된 모델을 배포 가능한 형태로 변환하는 도구 세트 Neat 런타임은 다음 환경에서 실행될 수 있습니다. MLSoC비전/ONNX 경로는 다음을 사용합니다. `afe` Python 호환성을 확인하고, 그래프를 준비하고, 양자화하고, 컴파일하고, 정확성과 성능을 검증하는 패키지입니다.
